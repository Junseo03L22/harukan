# 마음사이 0.2 · 두 휴대폰으로 테스트하기

## 시작

1. PC와 두 휴대폰을 같은 공유기에 연결합니다. PC는 유선 이더넷이어도 됩니다. 게스트 Wi-Fi는 기기끼리 통신을 막을 수 있습니다.
2. PC의 프로젝트 폴더에서 최초 한 번 `npm ci`를 실행합니다.
3. `npm run dev:pair`로 연결 서버와 앱을 함께 켭니다. 테스트 동안 이 창과 PC를 켜 둡니다.
4. 두 휴대폰의 Expo Go에서 표시된 QR 코드를 스캔합니다. 프로젝트는 Expo SDK 57입니다. 지원 버전이 맞지 않으면 호환되는 개발 빌드가 필요합니다.
5. 각자 캐릭터를 고른 뒤 **상대와 연결하기**를 누릅니다.
6. 한쪽에서 **초대 코드 만들기**, 다른 쪽에서 그 코드 8자리를 입력합니다. 코드는 10분 뒤 만료되며 한 번만 사용할 수 있습니다.

## 확인할 흐름

- 연결한 양쪽 홈에서 나와 상대 아바타의 위치가 서로 반대로 보이는지 확인합니다.
- 한쪽에서 신나·집중 중·쉬는 중을 선택하고 상대 화면에도 반영되는지 확인합니다.
- 캐릭터를 바꾸면 상대 쪽 캐릭터도 바뀌는지 확인합니다.
- 상태에는 선택 시각이 표시됩니다. 기기의 시계가 부정확하면 표시 시각도 달라질 수 있습니다.
- Wi-Fi를 잠깐 끊고 상태를 바꿉니다. 전달 대기가 표시되고 복구 후 마지막 상태가 전달되는지 확인합니다.
- 앱을 다시 열어 연결이 유지되는지 확인합니다.
- 연결 관리에서 공유를 중단하면 양쪽이 연결 전 화면으로 돌아오는지 확인합니다.

## PC에서 먼저 확인

`npm run server`와 `npm run web`을 각각 실행합니다. `http://localhost:8081`과 `http://127.0.0.1:8081`을 별도 창에서 열면 저장 공간이 분리되어 두 기기처럼 테스트할 수 있습니다. 같은 주소의 탭 두 개는 같은 사용자입니다. 브라우저 테스트가 휴대폰 실기기 검증을 대신하지는 않습니다.

## 연결이 안 될 때

- PC와 휴대폰이 같은 공유기에 연결되어 있는지 확인합니다.
- 연결 서버(8787)와 앱 개발 서버(보통 8081)가 둘 다 켜져 있는지 확인합니다.
- Windows가 방화벽 허용을 물으면 신뢰하는 개인 네트워크에서 Node.js를 허용해야 휴대폰이 접근할 수 있습니다. 앱은 방화벽 설정을 자동으로 변경하지 않습니다.
- `.env.example`을 `.env`로 복사한 뒤 `EXPO_PUBLIC_API_URL=http://PC의주소:8787`로 지정할 수도 있습니다. 변경 후 앱 개발 서버를 다시 시작합니다.
- 이미 같은 포트를 사용하는 서버가 실행 중이면 중복 실행하지 않습니다.

## 현재 테스트 범위

로그인 대신 기기에 발급된 연결 정보를 사용합니다. 앱 데이터 삭제 또는 재설치 후 연결 복구는 아직 지원하지 않습니다. 휴대폰에서는 보안 저장소, 브라우저에서는 해당 사이트 저장소에 연결 정보가 보관됩니다. 서버의 `server/data/state.json`은 연결과 상태를 유지하는 데이터 파일이므로 테스트 중 임의로 삭제하지 않습니다.

현재 서버는 같은 공유기 안에서 개발 테스트하는 용도입니다. 외부 인터넷 배포 전에는 HTTPS, 계정 복구, 운영용 저장소와 백업을 추가해야 합니다. 잠금화면 위젯은 추후 개발 범위이며 이번 버전에는 포함되지 않았습니다.

## 검증 기록

- 타입 검사 통과
- 자동 테스트 11개 통과: 기기 저장·복구, 연결, 즉시 업데이트, 코드 만료·취소·중복·자기 연결, 동시 가입, 연결 해제, 재시작 복원, 인증 및 접근 차단, 지연 업로드 시각
- 독립된 브라우저 두 개에서 코드 발급 → 연결 → 상태 변경 반영 확인
- 서버 중단 중 상태 변경 → 전달 대기 표시 → 서버 재시작 후 상대에게 최신 상태 전달 확인
- 휴대폰용 개발 실행 정보 요청 정상 응답 확인
- iOS·Android 실기기 테스트는 아직 수행하지 않음
