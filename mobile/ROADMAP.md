# 하루칸 개발 방향 · 2026-10-02

**하루를 붙이고, 한 달을 꾸미다.** 날짜별 사진 다꾸와 한 달 결과물이 제품의 중심입니다.

## 0.7 구현
- 월 달력 이미지 저장/공유와 일정 제목 포함 선택.
- 사진·GIF·영상 파일을 포함한 백업/복원, 복원 확인과 실패 처리.
- 구현/자동 검사 완료와 기기 QA 상태는 `docs/UPDATE-0.7.md`를 기준으로 구분합니다.

## 다음 패치: 비공개 테스트 준비
1. 새 Android APK 빌드. 기존 버전 위 업데이트 설치 후 기록 유지 확인.
2. 사진 이동·핀치·모서리 조절의 스크롤 충돌과 작은 조절점 사용성. 특히 기존 에뮬레이터에서 모서리 조절이 미검증.
3. 저장 완료·실패·재시도, 강제 종료 후 복원, 파일 누락/저장 공간 부족 확인.
4. 새 이미지 저장/공유와 백업·복원 왕복 테스트. 권한 거절, 파일 선택/공유 취소, 다른 기기로 복원 확인.
5. 처음 사진을 붙이는 흐름의 짧은 안내와 피드백 접수 방법. 기기·버전·재현 순서로 제보할 수 있도록 정리.

## 권장 비공개 테스트
- 먼저 5~10명을 모집해 1~2주 사용. 이는 제안하는 초기 운영 규모이며 참여 확정 인원이 아닙니다.
- 모집은 시작하되 APK 배포는 위 저장/복원과 기본 조작 검증 이후 진행.
- 첫날 사진 하나 붙이기, 며칠 뒤 다시 기록하기, 월 결과물 저장, 백업/복원 흐름 확인.
- 사용자가 설명 없이 첫 기록을 완성하는지, 다시 쓰고 싶은지, 월 달력을 간직하거나 공유하고 싶은지 관찰.
- 기록 손실/실행 불가/복원 실패는 배포 중단 및 우선 수정. 익숙해지기까지 필요한 조작 설명을 수집.
- 1~2주에는 월 완성까지 검증할 수 없으므로 일부 참여자는 4주까지 이어가며 월말 경험을 확인.

## 그 다음
실사용 피드백에 따라 가벼운 월 회고, 꾸미기 에셋, 날짜·텍스트 검색을 순차 검토합니다. AI 누끼와 클라우드 동기화는 실제 수요와 비용·복구 설계를 확인한 뒤 진행합니다. 영화/책 DB, 별점, 공개 피드와 팔로우는 현재 우선순위가 아닙니다.
