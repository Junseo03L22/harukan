# 마음사이 · 모바일 0.2

살구·삐코·모루로 내 상태를 표현하고, 초대 코드로 연결한 상대의 상태를 함께 보는 Expo / React Native 앱입니다.

## 이번 업데이트

- 10분 동안 유효한 일회용 초대 코드로 한 사람과 연결
- 홈에서 두 아바타, 각자의 상태와 변경 시각 표시
- 상태·캐릭터 변경 즉시 전달: 서버가 변경을 기다렸다가 응답하는 long polling 방식
- 연결 중단 시 마지막 상태와 전달 대기 표시, 복구 후 마지막 선택 재전송
- 연결 해제 시 양쪽의 상태 공유 중단
- 서버를 재시작해도 연결과 상태 유지
- 기존 캐릭터 선택, 여섯 상태, 눈 깜빡임, 4초 뒤 딴짓, 기기 저장 유지

## 실행

Node.js 22.13 이상에서 실행합니다.

```sh
npm ci
npm run dev:pair
```

PC와 두 휴대폰을 같은 공유기에 연결하고 Expo Go에서 QR 코드를 스캔합니다. 자세한 안내는 [TESTING.md](TESTING.md)에 있습니다. 현재 버전은 같은 Wi-Fi 테스트용이며 별도 서버 계정은 필요하지 않습니다.

PC에서 웹 미리보기를 사용할 경우 개발 터미널에서 `w`를 누르거나, 연결 서버를 켜고 별도로 `npm run web`을 실행합니다.

```sh
npm test
npm run typecheck
npm run export
```

`export`는 iOS·Android·웹의 코드와 이미지를 묶습니다. 설치 가능한 APK/IPA 생성이나 스토어 배포를 뜻하지 않습니다. 개발 중에는 Expo PC의 주소를 자동으로 찾으며, 배포용 빌드에는 `EXPO_PUBLIC_API_URL`로 HTTPS 서버 주소를 지정해야 합니다.

## 주요 파일

- `App.tsx`: 내 아바타 설정과 상태 홈
- `src/Avatar.tsx`: 눈 깜빡임과 대기·상태별 동작
- `src/ConnectionPanel.tsx`: 두 아바타, 초대·입력·해제 화면
- `src/useConnection.ts`: 상태 전송, 변경 수신, 오프라인 복구
- `src/connection.ts`: 서버 주소, 기기 연결 정보 보관
- `server/server.mjs`: 인증, 초대, 1:1 연결, 실시간 상태 API
- `server/data/`: 실행 중 생성되는 개인 데이터. 배포 파일에 포함하지 않음
- `TESTING.md`: 실행 및 확인 방법
- `ROADMAP.md`: 잠금화면 위젯을 포함한 다음 개발 범위
- `ASSETS.md`: 캐릭터 이미지 출처와 생성 프롬프트

## 남은 범위

잠금화면 위젯은 다음 단계입니다. 상대의 아바타·상태·마지막 업데이트를 잠금을 해제하지 않고 볼 수 있도록 계획했습니다. 홈 화면 위젯, 상태 영수증, 계정 복구 및 외부 서버 배포도 아직 포함되지 않았습니다.
