# 마음사이 개발 방향

## 0.2 · 이번 범위

- 한 번 사용할 수 있는 초대 코드로 한 사람과 연결
- 홈에서 나와 상대의 아바타 및 상태를 함께 보기
- 상태와 캐릭터 변경을 연결된 상대에게 실시간 전달
- 상태 변경 시각, 오래된 상태, 연결 끊김 표시
- 연결 해제 및 재초대
- 같은 Wi-Fi에서 PC 연결 서버로 두 휴대폰 테스트

## 다음 범위

1. **잠금화면 위젯**: 잠금을 해제하지 않고 상대의 아바타·상태·업데이트 시각 확인. iOS와 Android의 지원 범위 및 업데이트 제약을 실제 개발 시 확인한다. 화면이 꺼진 상태의 상시 표시는 기기 지원 여부에 따라 별도로 검토한다.
2. 홈 화면 위젯
3. 원하는 반응 선택과 간단한 응답
4. 상태 영수증

## 외부 테스트와 출시 전

- HTTPS 서버 배포와 지속 저장소, 백업 및 운영 설정
- 계정 복구·기기 변경, 데이터 삭제 기능
- 두 휴대폰 실기기 테스트, 네트워크 전환·재접속 검증
- 잠금화면에 표시할 정보 선택 및 숨기기 설정
- 앱 서명, 스토어 등록
