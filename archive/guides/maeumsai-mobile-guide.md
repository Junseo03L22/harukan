# 마음사이 · 모바일 첫 버전

아이폰과 안드로이드용 Expo / React Native 프로젝트입니다. 브라우저 미리보기도 같은 앱 코드를 실행합니다.

## 구현된 기능

- 첫 실행에서 살구(살구색 생명체), 삐코(로봇), 모루(조약돌) 선택
- 아바타 변경 화면에서 미리 보고 적용 또는 취소
- 평온해 / 신나 / 지쳤어 / 집중 중 / 복잡해 / 쉬는 중: 상태별 그림
- 평온 상태에서 첫 4초는 몸을 움직이지 않고 눈만 깜빡임. 이후 캐릭터별 몸 흔들기·기울이기·좌우 구르기
- 눈을 별도 레이어로 구현해 깜빡일 때 입이나 얼굴이 변하지 않음
- 캐릭터·상태 변경 또는 아바타 터치 시 4초 대기 초기화
- 화면 비활성화 시 동작 중단, 복귀 시 대기부터 재시작
- 기기의 동작 줄이기 설정 존중
- 캐릭터와 상태 기기 저장. 저장 실패 안내와 재시도, 연속 선택 시 저장 순서 보장

## 실행 방법

Node.js 22.13 이상이 설치된 PC에서 이 폴더를 열고 실행합니다.

```sh
npm ci
npm start
```

휴대폰에서 프로젝트 SDK를 지원하는 Expo Go를 열고 같은 Wi-Fi에서 QR 코드를 스캔합니다. 프로젝트는 Expo SDK 57입니다. Expo Go의 지원 버전이 맞지 않으면 SDK 57용 개발 빌드가 필요합니다.

PC에서 미리보기:

```sh
npm run web
```

## 검증 명령

```sh
npm run typecheck
npm test
npm run export
```

export는 iOS·Android·웹의 JavaScript와 이미지 묶음을 생성합니다. 설치 가능한 APK/IPA를 만드는 명령은 아닙니다. 실제 스토어 빌드 전에 앱 식별자, 서명, 개발자 계정 설정이 필요합니다.

## 구조

- App.tsx: 첫 실행 선택, 내 상태 화면, 아바타 변경
- src/Avatar.tsx: 눈 깜빡임, 4초 대기, 상태별 움직임
- src/model.ts: 캐릭터 이름과 상태 목록
- src/storage.ts: 기기 저장 및 쓰기 순서 관리
- assets/avatars: 기본 몸체 3개와 상태 이미지 18개
- tests/storage.test.cjs: 저장 복구, 연속 변경, 실패 후 재시도 검사

## 범위

상대 연결, 실시간 상태 공유, 홈 화면 위젯, 상태 영수증, 로그인은 다음 단계입니다. 현재 상태는 이 기기에만 저장됩니다. 아이폰·안드로이드 실기기 검증과 스토어 배포는 아직 하지 않았습니다.
