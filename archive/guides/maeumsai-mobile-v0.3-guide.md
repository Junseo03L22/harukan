# 마음사이 0.3 테스트 안내

아이폰 Expo Go에서 현재 프로젝트를 다시 열거나 Reload를 누르세요.

1. 상태 버튼을 누르고 원하는 반응을 고르거나 80자 이내로 적습니다.
2. 상태 남기기를 누르면 아바타와 반응이 함께 저장됩니다. 취소하면 기존 상태가 유지됩니다.
3. 건너뛰면 이전 반응을 지우고 상태만 남깁니다.
4. 연결된 상대의 아바타 아래에서 알겠어를 누르면 보낸 사람에게 확인 표시가 나타납니다.
5. 상태나 반응을 다시 남기면 이전 확인 표시가 초기화됩니다.

여자친구가 없어도 PC 브라우저와 아이폰을 초대 코드로 연결해 양쪽 동작을 확인할 수 있습니다. 현재는 같은 내부 네트워크와 PC 서버가 필요합니다. 잠금화면 위젯은 후속 개발 범위입니다.

검증: 자동 테스트 13개, TypeScript 검사. iPhone에서 새 화면의 직접 조작 확인은 필요합니다.
