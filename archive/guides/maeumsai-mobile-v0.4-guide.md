# 마음사이 0.4 · 내 친구의 작은 방

## 이번 버전
- 홈의 중심을 아바타 방과 돌보기로 변경했습니다.
- 하루 한 번 간식을 주면 누적 돌봄 일수가 올라가고 잠깐 기뻐합니다. 3일마다 레벨이 오릅니다.
- 1일 화분, 3일 별빛 모빌, 5일 살구 쿠션이 열립니다. 방 꾸미기에서 하나를 골라 배치합니다.
- 쉬어도 성장 기록이 줄지 않으며 아바타를 바꿔도 기록은 유지합니다.
- 연결된 상대의 방에 방문해 아바타, 상태, 방 꾸미기와 한마디를 봅니다.
- 상태는 한 번 눌러 즉시 변경합니다. 상대에게 한마디는 별도로 작성/삭제합니다.
- 알겠어는 한마디가 있을 때만 나타납니다. 상태나 돌보기 변경에는 유지되고, 한마디 변경/삭제 또는 연결 해제 시 초기화됩니다.

## 아이폰 확인
Expo Go에서 프로젝트를 다시 열거나 Reload 하세요. PC와 같은 Wi-Fi 연결을 유지하세요.
1. 간식 주기 → 누적 1일과 오늘 간식 먹었어 표시를 확인합니다.
2. 방 꾸미기 → 초록 화분을 선택하고 앱을 다시 열어 유지되는지 확인합니다.
3. 내 상태는? → 선택 즉시 변경되고 추가 화면이 열리지 않는지 확인합니다.
4. 상대에게 한마디 → 작성 후 다른 상태를 선택해 한마디가 유지되는지 확인합니다.
5. PC 브라우저와 아이폰을 초대 코드로 연결하면 여자친구 없이도 상대의 방을 테스트할 수 있습니다.

## 검증 및 현재 한계
자동 테스트 15개와 TypeScript 검사로 저장, 날짜 중복, 보상 조건, 방 공유, 한마디 확인 유지/초기화를 검증했습니다.
UI 자동화 도구의 커널 경로 오류로 이번 화면의 시각 검증은 완료하지 못했습니다. 아이폰 직접 확인이 필요합니다.
돌보기는 기기 날짜/로컬 기록을 사용하는 프로토타입입니다. 유료 재화와 서버 기반 보상 검증은 없습니다. 기기 변경 복구, 외부 HTTPS 서버, 잠금화면 위젯과 선물 보내기는 후속 범위입니다.
