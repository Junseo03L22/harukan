2. 위로에 한정하지 않고 서로의 현재 상태를 한눈에 보는 앱으로 정리. 채팅은 필수 아님.
3. 상태 아바타, 추후 위젯, 부가 기능인 상태 영수증을 구상.
4. 살구/삐코/모루 제작. GIF는 v1 → 20fps → 눈/표정 고정 손 흔들기 순으로 수정.
5. 모바일 프로젝트 선택. 0.1 아바타 선택/상태/애니메이션 및 로컬 저장.
6. 0.2 같은 LAN 서버, 일회용 초대/1:1 연결, 상대 상태 동기화 구현.

8. 0.3 상태 선택 후 원하는 반응, 알겠어 추가.
9. 사용자 피드백: 상태 변경마다 반응 선택이 번거로워 별도 기능으로 분리 요청.
10. 0.4 육성 메인/소통 보조로 전환. 작은 방, 간식, 누적 성장, 꾸미기 보상, 상대 방 방문 구현. 상태 변경과 한마디 편집 분리.
