# 하루칸 0.7.0 · 2026-10-02

## 한 달을 이미지로 간직하기
- 월 전체 달력 → `이 달 이미지 저장 · 공유` → 미리보기 → 이미지 저장 / 공유하기.
- 연월, 요일, 날짜별 사진·누끼·4컷·장식·종이 배경을 담는 PNG. 가로 1600px, 높이는 달력 비율에 맞춤.
- 일정 제목은 기본 제외하며 선택해서 포함. 첫 제목과 추가 일정 개수만 표시하고 메모·시간은 내보내지 않음.
- GIF는 정지 프레임, 영상은 저장된 썸네일로 표시. 애니메이션/영상 내보내기는 지원하지 않음.
- 이미지 로드를 기다린 뒤 캡처하고 실제 생성된 PNG를 미리보기에 표시. 실패하면 재시도 가능.
- Android/iOS: 사진 앨범 저장 및 OS 공유창. 웹: PNG 다운로드, 파일 공유 지원 브라우저의 공유창.
- 찢어진 종이 배경이 사진 위를 덮어 사진이 비어 보이는 현상을 수정. 사진 레이어를 종이 배경 앞에 배치하고 기존 보정·누끼 렌더러 유지.

## 백업 및 복원
- 홈 → `기록 백업 · 복원`.
- 사진, GIF, 영상, 영상 썸네일, 4컷 사진, 꾸미기, 일정, 내 스티커와 과거 월 여백 데이터를 하나의 JSON 파일로 보관.
- 동일한 원본은 중복 저장하지 않음. 원본 파일은 Base64로 포함하고 간단한 체크섬으로 우발적 손상 검사.
- 최대 100MB. 대규모 장기 기록용 스트리밍/분할 백업은 후속 범위. 파일은 암호화되지 않음.
- 복원 전 날짜·미디어·스티커 개수를 보여주고 현재 기록 전체 교체를 확인. 병합 복원은 지원하지 않음.
- 형식·참조·미디어 목록을 검증한 뒤 새 이름으로 파일을 만들고 마지막에 앨범 메타데이터 저장. 실패 시 이번 복원의 임시 파일 정리. 기존 파일은 삭제하지 않음.
- 파일 앱이나 원하는 외부 보관 장소에 직접 저장해야 함. 자동 백업/클라우드 동기화는 미구현.
- 기존 AsyncStorage/IndexedDB 이름 유지. 웹↔기기 파일 표현 차이는 가져오기/내보내기 어댑터에서 변환.

## 검증과 배포 상태
- 자동 테스트 30개와 TypeScript 검사 통과. 백업 중복 제거, 누락/손상/외부 경로 거절, 파일 쓰기 실패와 메타데이터 저장 실패 시 복원 중단 테스트 포함.
- Android/iOS Hermes 및 웹 번들 export 통과. 최종 재검증 결과는 HANDOFF.md에 기록.
- 브라우저에서 샘플 백업 선택·검사·복원·재실행 후 사진/일정 유지 확인. 사진·누끼·4컷·GIF가 있는 월 이미지 생성 및 일정 포함 옵션 확인.
- 인앱 브라우저의 다운로드 완료 이벤트/저장 경로는 확인되지 않아 실제 다운로드 파일 저장 성공은 미검증. 생성된 PNG 자체는 화면과 로컬 QA 파일로 확인.
- **0.7 APK는 아직 빌드·기기 검증하지 않음.** 새로운 네이티브 모듈이 포함돼 0.6 APK를 그대로 쓸 수 없음. 미디어 라이브러리/문서 선택/공유/캡처를 포함해 새 preview APK 필요.
- Android/iOS 사진 저장 권한 허용·거절, OS 공유 수신 앱, 네이티브 복원과 저장 공간 부족, 큰 백업 파일 메모리 사용량은 실기기 검증 필요.
