# 사진 캘린더 0.5.0 — 2026-09-22
현재 제품은 사진으로 꾸미는 캘린더입니다. 아바타 육성 및 마음 전달 기능은 보류했습니다.

## 사용법
1. 날짜를 선택하고 아래의 사진 붙이기 또는 촬영을 누릅니다.
2. 사진 전체 장면을 그대로 붙이고, 끌어서 이동합니다. 선택 후 크기/회전을 조절합니다.
3. 필요할 때 직접 누끼 따기를 엽니다. 둘러서 남기기, 지우개, 복원, 되돌리기, 원본으로를 사용할 수 있습니다.
4. 저장한 누끼는 내 스티커 보관함에서 다른 날에도 재사용합니다.
5. 하트, 반짝, 꽃, 새싹, 햇살, 구름 기본 스티커와 세 가지 종이를 제공합니다.

## 실행
mobile에서 npm ci 후 npm start를 실행합니다. Expo Go는 같은 LAN에서 개발 서버에 연결합니다.
현재 캘린더는 기존 8787 페어링 서버를 필요로 하지 않습니다. 테스트 중 PC의 Expo 서버는 켜 두어야 합니다.
Expo CLI와 iPhone Expo Go는 같은 계정으로 로그인합니다. EXPO_OFFLINE은 사용하지 않습니다.

## 코드
App.tsx는 src/calendar/CalendarApp.tsx를 실행합니다.
Editor.tsx: 수동 누끼 도구. Artwork.tsx: 사진 마스크 및 기본 SVG 스티커.
model.ts: 달력/사진/스티커 모델과 저장 검증. storage.ts: 가져오기 및 직렬 저장.
LegacyApp.tsx와 기존 src 코드에 0.4 아바타 앱을 보존했습니다. 기존 프로필 저장 키도 유지합니다.

## 저장과 한계
- 휴대폰 앨범 원본은 수정하지 않습니다. 앱용 복사본은 긴 변 최대 1600px JPEG로 압축합니다.
- 네이티브는 앱 문서 폴더, 웹은 브라우저 로컬 저장소를 사용합니다. 앱 삭제/브라우저 데이터 삭제 시 사라질 수 있으며 백업/동기화는 미구현입니다.
- 누끼는 비파괴 마스크로 저장합니다. AI 자동 추출, 확대 정밀 편집, 투명 PNG 내보내기, 달력 이미지 공유는 미구현입니다.
- 월 달력은 날짜 페이지 전체를 같은 비율로 축소합니다. 모든 항목의 위치, 크기, 회전, 겹침 순서와 누끼가 동일하게 반영됩니다. 완료 버튼은 저장 성공 후 선택을 해제하고 캘린더로 돌아갑니다.
- 기기 테스트 사진이나 로그인 정보는 Git 저장소에 포함하지 않았습니다.
- 네이티브 촬영, 사진 권한, 손가락 제스처는 실제 iPhone 추가 확인이 필요합니다.

iOS/Android/Web 프로덕션 번들 생성 통과. 스토어용 바이너리/배포 완료를 의미하지 않습니다.

- 브라우저에서 GIF 가져오기, 78→83% 확대, 윤년 날짜 이동, 4초 영상 실제 재생, 7초 영상 거절 확인. iPhone 실기기 미검증.
