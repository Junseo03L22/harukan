# 맥북 / 다른 Windows PC에서 실행

1. GitHub 저장소를 clone하고 저장소 루트를 Codex 프로젝트로 엽니다.
2. Node.js 24를 설치합니다. 이 프로젝트의 Expo 57 최소 Node 요구는 22.13이지만 기존 개발과 맞추려면 24를 사용합니다.
3. 터미널에서 다음을 실행합니다.
```sh
cd mobile
npm ci
npx expo login
npm test
npm run typecheck
npm run dev:pair
```
Expo 웹사이트 로그인과 CLI 로그인은 별도입니다. 아이폰 Expo Go와 CLI에 동일한 테스트 계정으로 로그인해야 합니다. 비밀번호/토큰을 저장소에 넣지 않습니다.
이전 PC의 work/expo-local-state는 복사하지 않았습니다. 새 컴퓨터에서 정상 로그인하세요. EXPO_OFFLINE을 설정하지 마세요.

## 휴대폰
PC/맥과 iPhone을 같은 내부 네트워크에 연결하고, 실행 후 새로 나온 QR을 카메라로 스캔합니다. 예전 QR은 IP가 달라 사용할 수 없습니다.
개발 앱 포트는 8081, 상태 공유 서버는 8787입니다. 서버 주소는 Expo 호스트에서 자동 감지합니다. 휴대폰 Safari에서 http://현재PC주소:8787/health 가 열리고 {"ok":true}가 나오면 API 연결이 됩니다.
다른 네트워크에서 사용하려면 별도 HTTPS 서버 구성이 필요합니다. Expo 터널만 켜도 8787 API까지 공개되는 것은 아닙니다.

## 데이터와 이전 연결
서버의 실제 상태/초대/인증 파일과 기기 로컬 저장은 GitHub에 올리지 않습니다. 새 PC는 새 테스트 서버이며 새 연결이 필요합니다. 같은 기기에 옛 서버 인증이 남아 401이 발생하면 개발자가 세션 재설정 방법을 마련해야 합니다. 기존 데이터 삭제를 자동으로 가정하지 마세요.
Windows 방화벽 스크립트는 과거 특정 LAN용 참고 자료입니다. 맥에서는 실행하지 않으며 새 네트워크에서 그대로 적용하지 않습니다.

## 첫 확인
간식 주기 → 화분 해제 → 방 꾸미기 → 화분 선택 → 재시작 후 유지 확인.
상태 버튼은 추가 화면 없이 반영. 한마디는 별도 저장. 상대 방에서 알겠어를 누른 후 상대의 상태 변경만으로 확인이 사라지지 않는지 확인.
