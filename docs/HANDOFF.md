# 새 Codex 작업을 위한 인수인계

## 현재 상태
2026-09-18 정리. 마지막 구현은 0.4.0. 작업 위치는 mobile/. React Native + Expo SDK 57, React 19, TypeScript 6, 의존성 없는 Node HTTP API.
두 사용자 모두 iPhone. 사용자의 iPhone에서 0.2 실행 성공 확인. 0.3/0.4는 자동 테스트/번들 생성 통과했으나 실제 새 화면의 iPhone 사용 검증은 아직 기록되지 않았습니다. 0.4 UI 자동화 도구가 커널 경로 오류로 실행되지 않아 시각 검증 미완료.
유료 Apple 개발자 계정 및 운영 서버 없음. TestFlight 배포, 스토어 등록, 외부 네트워크 지원을 완료했다고 말하지 마세요.

## 최종 제품 방향
각자 키우고 서로 들여다보는 아바타 앱. 육성과 방 꾸미기를 메인, 상태 공유와 한마디는 보조로 둡니다. 성별/MBTI를 이용 조건으로 제한하지 않습니다. 위로에만 치우치거나 감정적인 문구를 과도하게 늘리지 않습니다.
혼자서도 돌볼 수 있고 상대의 접속/답장/출석에 성장 조건을 걸지 않습니다. 며칠 쉬어도 벌점/퇴화 없음.

## 구현
- 살구(살구색 생명체), 삐코(로봇), 모루(조약돌) 중 선택 및 변경
- 6개 상태: 평온해, 신나, 지쳤어, 집중 중, 복잡해, 쉬는 중
- 기본 상태에서 눈 깜빡임, 첫 4초 이후 딴짓 동작; 동작 줄이기/백그라운드 대응
- 자기 방/상대 방 방문, 상태에 따른 이미지와 소품
- 하루 한 번 간식, 누적 일수/레벨; 1일 화분, 3일 모빌, 5일 쿠션 해제 및 선택
- 상태는 즉시 변경. 한마디는 별도로 80자 이내 작성/삭제
- 한마디가 있을 때 알겠어; 상태/돌보기/꾸미기 변경에는 유지, 한마디 변경/연결 해제 시 초기화
- 일회용 초대 코드, 1:1 연결/해제, long polling, 오프라인 마지막 상태 및 재전송
- AsyncStorage 프로필, 네이티브 SecureStore 세션, 서버 JSON 영속화 및 해시 토큰

## 주요 코드
App.tsx: 온보딩, 프로필 저장, 즉시 상태 변경, 한마디 편집.
src/Room.tsx: 방과 방문, 간식 피드백, 꾸미기.
src/model.ts: 모델, 성장/일자/보상 검증.
src/Avatar.tsx: 이미지 및 RN Animated 모션.
src/connection.ts, useConnection.ts: 서버 주소/인증/동기화.
server/server.mjs: API, 초대/연결, 상태 버전 및 한마디 확인, JSON 저장.
tests/: 저장소 및 실제 HTTP 통합 테스트. 현재 15개.

## 중요한 제약
- 돌보기 기록은 클라이언트 날짜/입력 기반. 유료 재화/서버 권위 검증 없음.
- 하루 기준은 실행 기기의 로컬 날짜이며 이전 날짜로 돌아갈 때 중복 보상 차단. 기기 시간 조작의 완전 방지는 아님.
- 서버 주소별 세션 키이므로 PC IP 변경 시 기존 연결이 자동 복구되지 않을 수 있음.
- 복제본은 실제 서버 데이터와 기기 세션이 없음. 새 서버에서는 새 초대 연결 필요.
- 운영 HTTPS 서버, 계정 복구/삭제, 푸시, 위젯, 선물, 채팅, 상태 영수증은 아직 미구현.
- Expo 시작에 EXPO_OFFLINE=1을 쓰지 말 것. 과거 iPhone 로그인 오류 원인이었음.
- 이미지 제작 스크립트는 과거 Windows 절대 경로/번들 라이브러리 경로 사용. 앱 실행에는 불필요. 재사용 시 경로 이식 필요.
