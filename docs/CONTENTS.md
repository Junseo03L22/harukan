# 정리 범위

현재 mobile 소스와 모든 앱 에셋, 테스트, 원래 문서를 복사했습니다. 초기 웹 소스, 과거 0.1~0.3 ZIP 내부 코드, 이전 안내문, 생성 이미지 7개, GIF 3개, 제작 스크립트/검토 이미지도 보존했습니다. 0.4 최신본은 mobile/이므로 중복 ZIP은 넣지 않았습니다.

제외: node_modules, 빌드 산출물, 캐시, Expo 로그인 상태, 실제 server/data, .env(예제 제외), 기기 인증서, .git 이력, 배포 서비스 연결 메타데이터(.openai), 개인 도구 설정(.claude), 과거 PC IP를 담은 접속 QR, 중복 tar/ZIP 및 중복 staging 폴더.
원래 작업 폴더/데이터는 삭제하지 않았습니다. 개발 산출물 보관용이며 운영 데이터 백업은 아닙니다.

과거 가이드의 IP/경로/버전/완료 표현은 당시 기록입니다. 현재 기준은 docs/HANDOFF.md와 SETUP.md입니다. 제작 스크립트의 Windows 경로는 역사 기록으로 유지했으며 맥 실행에 맞춰 검증한 스크립트가 아닙니다.

FILE-MANIFEST.json은 정리 시점의 파일 크기와 SHA-256입니다. 이후 코드를 수정하면 해시가 달라지는 것은 정상입니다.
